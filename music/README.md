# Music library

Drop **royalty-free / no-copyright** background tracks here (`.mp3`, `.m4a`,
`.wav`). `studio.py` lets you pick one per project (or *Random*), and
`assemble.py --music` ducks it under the narration (`MUSIC_GAIN = 0.12`) with a
fade at the end.

## Safe sources (free, cleared for monetized YouTube)

- **YouTube Audio Library** — studio.youtube.com → Audio Library (filter to
  "No attribution required"). The safest option for YouTube specifically.
- **Pixabay Music** — pixabay.com/music (CC0-style license).
- **Uppbeat** — uppbeat.io (free tier, some tracks need a credit).
- **Chosic**, **Free Music Archive** — check each track's license.

## Not here on purpose

Actual TikTok/chart "trending" songs are **copyrighted**. On YouTube they trigger
Content ID claims, demonetization, or strikes. Keep them out of this folder — the
pipeline is built around cleared audio so uploads stay safe.

## Naming

Short, descriptive filenames help when picking in the UI, e.g.
`lofi-tense-loop.mp3`, `ambient-dark-swell.mp3`.
